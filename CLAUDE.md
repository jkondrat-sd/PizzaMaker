# PizzaMaker — project rules

## Git commits

- Author every commit as the sole developer. Subjects and bodies use the
  imperative, first-person singular — "Add rate-limit config", "Fix null check".
  Never "we", "let's", "I've gone ahead".
- **No AI or tool attribution anywhere** — no `Co-Authored-By: Claude`,
  `Generated with Claude Code`, `Claude-Session`, or any variant, in commit
  messages, trailers, or PR bodies. Also enforced by `.claude/settings.json`
  (attribution disabled) and the `.githooks/commit-msg` hook.
- Match the surrounding code's comment density and idiom. No decorative block
  headers, no explanatory comments on obvious code, no "generated by" notices.

## Hook setup

`npm install` runs `git config core.hooksPath .githooks` via the `prepare`
script, activating `.githooks/commit-msg`. If commits are made before an install,
run that command once by hand.
